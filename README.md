# Трекер личных финансов

## Назначение

Приложение помогает пользователю контролировать личный бюджет: учитывать доходы и расходы, рассчитывать остаток средств и сравнивать расходы с установленным лимитом.

## Целевая аудитория

Студенты и другие пользователи, которым нужен простой инструмент для контроля личных финансов и планирования ежемесячных расходов.

## Предметная область

Предметная область — учёт личных финансов. В дальнейшем приложение будет хранить операции пользователя, категории доходов и расходов, бюджеты и финансовые цели.

## Основные сущности

- пользователь;
- финансовая операция;
- категория операции;
- бюджет;
- финансовая цель.

## Основные функции

- проверка корректности введённых финансовых данных;
- расчёт остатка средств по доходам и расходам;
- проверка соблюдения установленного лимита расходов;
- расчёт доли остатка от дохода.

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей, регистрации и авторизации;
- создание операций добавления, просмотра, изменения и удаления данных;
- разработка REST API;
- контейнеризация приложения с помощью Docker;
- настройка CI/CD.
