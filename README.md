# Система учёта облачных ресурсов

Консольная программа для учёта пользователей, облачных ресурсов,
провайдеров и расходов на облачную инфраструктуру.

## Сущности

- пользователь: id, имя, email;
- провайдер: id, название;
- ресурс: id, пользователь, провайдер, название, тип;
- расход: id, пользователь, ресурс, сумма, дата.

## Что сделано

В проекте используются списки и словари, циклы, отдельные модули,
поиск и фильтрация, сортировка через lambda, генератор, обработка
исключений, чтение и запись JSON, аннотации типов и тесты pytest.

## Запуск

```bash
py -m pip install -r requirements.txt
py main.py
```

## Тесты

```bash
py -m pytest
```
